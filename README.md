# Фабрика роликов «Окно дня»

Три вертикальных ролика в день для канала [@oknodnya](https://t.me/oknodnya) о проекте [Лофи-города](https://lofi-goroda.ru).
Без сторонних ИИ-сервисов: сцена — запись живого окна сайта, музыка и дождь — синтез кодом, голоса — свободный синтезатор RHVoice,
истории, сценарии и проверка — Claude.

## Как работает каждый день

| Когда (МСК) | Кто | Что |
|---|---|---|
| 18:00 накануне | Claude (ежедневная задача, см. `ROUTINE.md`) | пишет 3 истории на завтра, собирает их, смотрит кадры, ставит `"approved": true`, отправляет `content/<дата>.json` в репозиторий |
| 06:00 | сервер, `okno-build.timer` | `git pull` → запись сцен сайта → сборка → техпроверка → превью владельцу в личку бота |
| каждые 5 минут, до 23:30 | сервер, `okno-due.timer` | ролик с `approvals/<дата>-N.ok` и `QA-OK` уходит в канал в свой слот (09:00 / 14:00 / 20:00) или сразу после одобрения, если слот уже прошёл. Журнал `log/posts.csv` |

Нет файла `content/<дата>.json` с `"approved": true` — владельцу одно предупреждение, без файла сборка не начинается. `"approved": false` сборку не останавливает.

## Автопубликация и алерты

В `/etc/oknodnya.env` строка `OKNO_AUTO_PUBLISH=1` включает автопубликацию. Пусто, `0` и любое другое значение — прежний режим: под превью кнопки «✅ В канал / ⏭ Пропустить», без файла `.ok` ролик в канал не выходит.

С флагом, после успешной сборки и `QA-OK`:
- `build` пишет `approvals/<дата>-N.ok` (внутри строка `auto`), если нет `approvals/<дата>-N.skip`. Если файла ещё нет, то же делает `due`;
- владельцу уходит превью «выйдет в HH:MM» и кнопка «⏭ Пропустить». Фразы «без ✅ не выйдут» и «ждёт ✅» не отправляются;
- `.skip` важнее `.ok`. Повторная сборка в тот же день стирает старый `.ok`, но уже нажатый ⏭ не снимает: чтобы выпустить пересобранный ролик, удалите `approvals/<дата>-N.skip`.

Алерты в `OKNO_OWNER_CHAT` приходят и без флага:
- сборка упала или ролик не прошёл QA — с причиной;
- к моменту сборки нет `content/<дата>.json` с `"approved": true`;
- одобренный ролик с `QA-OK` не опубликован: одно сообщение через 30 минут после его слота (ошибка `sendVideo`, сеть, нет файла). `due` повторяет попытки до 23:30 включительно и в 23:30 шлёт последнее «не вышел». Запуск при этом завершается с ошибкой (её видно в `systemctl`), но сначала пробуются остальные слоты, а в Telegram каждые 5 минут письмо не уходит.

Один и тот же алерт повторно не шлётся. Метка — `log/alerts/<ключ>.sent` (ключ — дата или дата и номер ролика). Удаление метки разрешает отправить его снова. Слоты и предел 23:30 не меняются. Юниты systemd те же: `EnvironmentFile` читается при каждом запуске oneshot-сервиса.

## Устройство
- `content/<дата>.json` — истории дня: хук, реплики (что сказать / субтитр / кто говорит / голос), сцены (адрес сайта с `?t=&d=&wx=&obs`), факты с источниками, текст поста.
- `recorder/record.js` — запись canvas сайта 480×270 в webm (Playwright).
- `build.py` + `factory/` — голос, музыка с приглушением под голос, сборка 1080×1920 (пиксели ×3 без размытия, размытый фон, заголовок, плашки «время · город», субтитры, имена в диалогах, шторы-разгадка, финальная карточка), −14 LUFS, H.264.
- `pipeline.py` — ежедневный конвейер сервера; `factory/publish.py` — Bot API.

## Установка на сервер
```bash
git clone https://github.com/kakaxy4-wq/oknodnya-factory /opt/oknodnya-factory
bash /opt/oknodnya-factory/deploy/install.sh
nano /etc/oknodnya.env          # токен @oknodnya_bot и ваш chat_id для отчётов
sudo -u okno /opt/oknodnya-factory/.venv/bin/python /opt/oknodnya-factory/pipeline.py build 2026-10-24   # пробная сборка
```
Бот должен быть администратором канала с правом публикации.

Таймер публикаций установщик ставит выключенным — включить, когда канал готов принимать ролики:
```bash
systemctl enable --now okno-due.timer
```
Без `OKNO_AUTO_PUBLISH=1` каждый ролик всё равно ждёт ✅ в личке. С этой строкой в `/etc/oknodnya.env` достаточно сборки и QA: `.ok` пишется сам, ⏭ до слота ролик снимает. Перезапуск юнитов после правки env не нужен — `okno-build` и `okno-due` запускаются заново по таймеру и каждый раз читают файл.

Фабрика только отправляет сообщения (sendVideo, sendPoll) и не читает входящие; комментарии, разгадку загадки и призы ведёт бот сайта по файлу approvals/quiz-ДАТА-N.json: тем же токеном может пользоваться бот на polling. Кнопки ✅/⏭ тоже обрабатывает бот сайта и кладёт решение в `approvals/`.
