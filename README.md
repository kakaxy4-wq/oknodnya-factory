# Фабрика роликов «Окно дня»

Три вертикальных ролика в день для канала [@oknodnya](https://t.me/oknodnya) о проекте [Лофи-города](https://lofi-goroda.ru).
Без сторонних ИИ-сервисов: сцена — запись живого окна сайта, музыка и дождь — синтез кодом, голоса — свободный синтезатор RHVoice,
истории, сценарии и проверка — Claude.

## Как работает каждый день

| Когда (МСК) | Кто | Что |
|---|---|---|
| 18:00 накануне | Claude (ежедневная задача, см. `ROUTINE.md`) | пишет 3 истории на завтра, собирает их, смотрит кадры, ставит `"approved": true`, отправляет `content/<дата>.json` в репозиторий |
| 06:00 | сервер, `okno-build.timer` | `git pull` → запись сцен сайта → сборка → техпроверка → отчёт владельцу в личку бота |
| 09:00 / 14:00 / 20:00 | сервер, `okno-publish@N.timer` | публикация ролика N в канал, своя ссылка-приглашение на каждый ролик, журнал `log/posts.csv` |

Нет одобренного плана — сервер ничего не публикует и пишет владельцу.

## Устройство
- `content/<дата>.json` — истории дня: хук, реплики (что сказать / субтитр / кто говорит / голос), сцены (адрес сайта с `?t=&d=&wx=&obs`), факты с источниками, текст поста.
- `recorder/record.js` — запись canvas сайта 480×270 в webm (Playwright).
- `build.py` + `factory/` — голос, музыка с приглушением под голос, сборка 1080×1920 (пиксели ×3 без размытия, размытый фон, заголовок, плашки «время · город», субтитры, имена в диалогах, шторы-разгадка, финальная карточка), −14 LUFS, H.264.
- `pipeline.py` — ежедневный конвейер сервера; `factory/publish.py` — Bot API.

## Установка на сервер
```bash
git clone https://github.com/kakaxy4-wq/oknodnya-factory /opt/oknodnya-factory
bash /opt/oknodnya-factory/deploy/install.sh
nano /etc/oknodnya.env          # токен @oknodnya_bot и ваш chat_id для отчётов
sudo -u okno /opt/oknodnya-factory/.venv/bin/python /opt/oknodnya-factory/pipeline.py build 2026-10-24   # пробная сборка
```
Бот должен быть администратором канала с правом публикации.
